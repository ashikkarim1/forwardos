# Forward OS: World-Class Notification System
## Email Strategy, Templates, & Preference Center

---

## EXECUTIVE SUMMARY

**Goal**: Create beautiful, branded, permission-based notifications that drive engagement without overwhelming users.

**Approach**:
- **3 distinct email types** per user (Buyers, Brokers, Sellers)
- **Smart frequency management** (not more than 2-3x per week)
- **Preference center** (granular controls)
- **Premium spotlight** (featured companies 2x/month minimum)
- **Trending data** (what's hot, what's matching your criteria)
- **Easy unsubscribe** (one-click, no questions asked)
- **Beautiful, responsive design** (Orange/dark theme, modern)

---

## USER TYPES & EMAIL STRATEGY

### 1. **BUYERS** (M&A Firms, Strategic Acquirers, Private Equity)

**Goal**: Help them find their next deal efficiently

**Email Cadence**:
- **Weekly "Deal Spotlight"** (Monday morning) — 2-3 deals matching their criteria + trending
- **Bi-weekly "Market Intel"** (Thursday) — Trends, comparables, market activity
- **On-demand "New Match"** (real-time) — New deal added matching saved criteria
- **Monthly "Your Stats"** (1st of month) — How many deals viewed, saved, comparison activity

**Content Strategy**:
- Lead with **1 premium featured deal** (if they pay)
- Show **2-3 best matches** based on saved filters
- Include **"Trending Now"** section (most viewed, hottest deals this week)
- Add **"You Compared This"** (deals they analyzed)
- Show **Market insights** (valuations by industry, growth trends)

**Frequency Cap**: 
- Max 3 emails/week
- User can set: Daily, 2x/week, Weekly, or Off

---

### 2. **BROKERS** (Investment Banks, M&A Advisors, Deal Facilitators)

**Goal**: Keep them updated on deal flow, buyers, and opportunities

**Email Cadence**:
- **Bi-weekly "Deal Flow Summary"** (Tuesday morning) — New deals in their categories + featured ones
- **Weekly "Buyer Activity"** (Thursday) — Which deals are getting interest, who's comparing
- **Monthly "Network Trends"** (1st of month) — Top performing brokers, deal velocity by region
- **On-demand "Deal Alert"** (real-time) — New deal added in their sectors

**Content Strategy**:
- Lead with **premium featured deal** (2x/month minimum)
- Show **5-7 new deals** in their categories
- Include **"Buyer Interest"** — which of their listed deals getting views
- Show **"Trending Categories"** — what buyers are searching
- Add **"Performance Metrics"** — how their deals compare
- Include **broker matching** — connect with other brokers on same deals

**Frequency Cap**:
- Max 3 emails/week
- User can set: Daily, 2x/week, Weekly, or Off

---

### 3. **SELLERS** (Business Owners, Portfolio Companies, PE Firms Divesting)

**Goal**: Get their business in front of the right buyers

**Email Cadence**:
- **Weekly "Your Listing Performance"** (Tuesday) — Views, saves, comparisons, buyer interest
- **Bi-weekly "Buyer Insights"** (Thursday) — Who's looking, what they care about, deal benchmarks
- **Monthly "Upgrade Opportunity"** (5th of month) — If free tier, show premium benefits with proof
- **On-demand "Serious Interest"** (real-time) — When a verified buyer engages with listing

**Content Strategy**:
- Show **listing performance metrics** (this week: X views, Y saved, Z comparisons)
- Highlight **buyer interest** (5 profiles viewed your listing, 2 saved it, 3 are running comparisons)
- Include **benchmark data** — how your deal compares to similar ones
- Show **"Upgrade Value"** — "With premium, your deal gets featured to 5K+ buyers weekly"
- Add **handholding tips** — "Pro tip: Add team bios - deals with team info get 40% more interest"
- Include **trending features** — "This week buyers are searching for: SaaS, 45%+ growth, <2M valuation"

**Frequency Cap**:
- Max 2 emails/week (they're busy running businesses)
- User can set: Weekly, 2x/month, Monthly, or Off

## BACKEND LOGIC & FREQUENCY MANAGEMENT

### **Email Scheduling Algorithm**

```typescript
// Pseudo-code: Email frequency manager

interface UserEmailPreferences {
  frequency: 'daily' | '2x-week' | 'weekly' | '2x-month' | 'off'
  dayOfWeek: 'mon' | 'tue' | 'wed' | 'thu' | 'fri' | 'any'
  timeOfDay: '6am' | '9am' | '12pm' | '3pm' | '6pm' | 'no-preference'
  contentTypes: string[] // 'new-deals', 'trending', 'stats', etc.
  dealFilters: DealCriteria
  lastEmailSent: Date
  unsubscribeToken: string
}

// Determine if user should receive email today
function shouldSendEmail(user: User): boolean {
  const prefs = user.emailPreferences
  
  if (prefs.frequency === 'off') return false
  
  const daysSinceLastEmail = daysBetween(prefs.lastEmailSent, today())
  
  switch (prefs.frequency) {
    case 'daily':
      return daysSinceLastEmail >= 1
    case '2x-week':
      return daysSinceLastEmail >= 3.5
    case 'weekly':
      return daysSinceLastEmail >= 7
    case '2x-month':
      return daysSinceLastEmail >= 14
    default:
      return false
  }
}

// Determine email content based on user type & activity
function buildEmailContent(user: User): EmailContent {
  if (user.type === 'buyer') {
    return {
      featured: getTopPremiumDeal(user.filters),
      matches: getRelevantDeals(user.filters, limit: 3),
      trending: getTrendingDeals(timeframe: 'this-week', limit: 3),
      stats: getUserActivityStats(timeframe: 'this-week')
    }
  }
  
  if (user.type === 'broker') {
    return {
      featured: getTopPremiumDeal(user.sectors),
      newDealFlow: getNewDeals(user.sectors, limit: 5),
      listingPerformance: getYourListingMetrics(user.id),
      buyerActivity: getWhoIsViewing(user.listings),
      brokerMatching: findCobrokerOpportunities(user.id)
    }
  }
  
  if (user.type === 'seller') {
    return {
      performanceMetrics: getYourListingStats(),
      buyerInterest: getWhoIsViewing(user.listings),
      comparison: compareAgainstSimilarDeals(user.listing),
      quickWins: getSuggestionsToBoostInterest(user.listing),
      upgradeOpportunity: (user.tier === 'free') ? getPremiumProposal() : null
    }
  }
}

// Ensure we don't overwhelm
const emailLimits = {
  buyer: { maxPerWeek: 3, maxPerMonth: 12 },
  broker: { maxPerWeek: 3, maxPerMonth: 12 },
  seller: { maxPerWeek: 2, maxPerMonth: 8 }
}
```

## UNSUBSCRIBE STRATEGY

### **Make it EASY to unsubscribe**

1. **One-click unsubscribe** (email footer)
   ```
   [Unsubscribe with one click]
   ```
   - No login required
   - No confirmation page
   - Instant

2. **Preference management** (easier than unsubscribe)
   - "Too many emails? Adjust frequency"
   - "Not interested in this category? Remove it"
   - Show they have control

3. **Resubscribe pathway**
   - Account Settings → Notifications → Easy re-enable
   - "Missed us? Turn emails back on"
   - Email from unsubscribed user shows "Resubscribe" link

## CONTENT STRATEGY: NOT OVERWHELMING, HIGHLY RELEVANT

### **The Golden Rule: 70/30 Mix**

- **70% Value**: Relevant deals, insights, benchmarks, performance data
- **20% Brand**: Premium features, success stories, tips
- **10% Upgrade**: Premium tier benefits (subtle, not pushy)

### **Frequency Sweet Spot**

For **Buyers**: 2-3 emails/week
- Mon: Weekly deal spotlight
- Thu: Market intel / trending
- (Optional) Fri: Real-time alert if hot deal matches

For **Brokers**: 2-3 emails/week
- Tue: Deal flow summary
- Thu: Buyer activity + trending
- (Optional) Real-time: New deal alert in their sector

For **Sellers**: 1-2 emails/week
- Tue: Weekly performance stats
- (Optional) Real-time: When serious buyer engages

### **What NOT to do**

❌ Daily emails about general trending (overwhelming)  
❌ Promotions mixed with deal data (noisy)  
❌ Irrelevant deals that don't match filters  
❌ Long emails (keep to 3-5 sections max)  
❌ Multiple CTAs competing (1-2 primary, 1 secondary)  
❌ Boring subject lines (no personality)  

### **Subject Line Examples**

**Buyers**:
- "Your perfect match: SaaS Platform +45% growth - Featured"
- "3 new deals + this week's trending (38 views)"
- "You saved this deal 👀 Here's the buyer interest"

**Brokers**:
- "New deal flow: 5 in your sector + buyer insights"
- "Your listing got 42 views (↑23%) — here's who"
- "Broker match: Sarah Chen is analyzing the same deals"

**Sellers**:
- "Your listing: 38 views, 3 serious buyers, top 20% quality"
- "SaaS Platform was featured 2x — here's the impact"
- "2 buyers downloaded your CIM — here's next steps"

## BRAND VOICE IN EMAILS

### **Tone**

- **Helpful, not salesy** — "Here's what's hot this week" not "Buy now!"
- **Data-driven** — Show numbers, metrics, proof
- **Conversational** — Like a trusted advisor, not a robot
- **Action-oriented** — Clear next steps
- **Respectful of time** — Short, scannable, valuable

### **Example copy**

**❌ Bad**: "Don't miss out on these incredible opportunities!"  
**✅ Good**: "3 new SaaS deals matching your criteria ($800K-$2M, 40%+ growth). Top performer from this week: 42 views in 3 days."

**❌ Bad**: "Join premium today for exclusive access!"  
**✅ Good**: "Sellers on premium get 5x the buyer visibility. Your deal quality deserves it."

**❌ Bad**: "Click here to learn more"  
**✅ Good**: "View CIM Dashboard" or "See buyer interest"
