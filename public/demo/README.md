# Dashboard tour screenshots

Drop PNGs here named:
- seller-dashboard.png
- buyer-dashboard.png
- broker-dashboard.png

Recommended: 1600×1000 PNG, lightly compressed (TinyPNG). Capture the live
dashboard with seeded sample data. Re-screenshot any time the dashboard
ships a visible change — the file paths are referenced by
src/components/DashboardTour.tsx.

If a screenshot is missing, the modal renders a polite "screenshot will
load here" placeholder so login isn't broken — but the demo experience is
weaker, so don't ship without these.
